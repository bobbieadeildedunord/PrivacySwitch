# What follows a PrivacySwitch profile — v105

| Item | Current scope |
|---|---|
| Available module membership and order | Each saved PrivacySwitch profile |
| Language and built-in/custom theme | Each saved PrivacySwitch profile |
| Windows privacy baseline/history | Each saved profile, Windows account and computer |
| Startup baseline, selection and monitoring choice | Each saved profile, Windows account and computer |
| Power User tool profiles/favourites | Separate Power User store; not linked to PrivacySwitch profile |
| DLP investigation flags/preferences | Separate user data; not linked through SavedProfile |
| DLP running watches, Keep awake and key hooks | Current app session; selection does not silently activate them |
| AI option switches | Current UI/session choices; no per-profile fields in SavedProfile |
| Encrypted-file jobs and operation inputs | Explicit individual operations, not profile-attached jobs |
| Start PrivacySwitch at sign-in | Account-wide app setting; not a runnable profile module |
| Device/network/USB/policy recovery records | Real recorded changes, deliberately shared across profiles |

Saving a profile does not apply its modules. Selecting another profile must not erase actual recovery originals. All module selections are saved; that does not mean every module option is already profile-bound. Extending option bindings is deferred beyond this pilot.
